# Scripts

In this folder, all scripts that I used for my Master's thesis so far can be found. 
The first two folders, `000_research_report_preliminary_results` and `00_presentation_research_report`,
are used for visualisation of simulated results, not based on SHARE data. 

Folders `01_data_cleaning` and `02_create_mutliverse` contain R scripts that can be used to analyse the SHARE data. 
**If you have not registered / were not yet able to access the data, please make sure to do so before trying to run these scripts (otherwise they will not work)!**
