# My Contribution

### Qmd Manuscript
To demonstrate my reproducible markup skills, I have created a .qmd manuscript about dog intelligence.
A .qmd file can be found that contains the full manuscript, as well as the rendered pdf and reference list (the .bib file), 
can be found in the `manuscript` folder, within the `Dog Quarto Manuscript` folder.

All data, scripts and images needed to run the .qmd file are also provided in this repository.

I made sure to only include relative paths, to ensure reproducibility. 
Before running the .qmd file, make sure to open the Rproject first!
